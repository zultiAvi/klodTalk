Idea 2: PreCompact/PostCompact Context-Guard Skill
----------------------------------------------------------------

Why: KlodTalk's hook coverage already spans PreToolUse, PostToolUse,
SubagentStart/Stop, and Stop. PreCompact/PostCompact were the missing
pair. Long Coder/Planner runs using the Compaction API risk silent task-
context loss when the summarizer de-prioritizes in_message.txt or pipeline
stage state; a snapshot hook lets operators inspect what was preserved.

Changes:
- CLAUDE/skills/precompact-context-guard.md (NEW)
    * Documents PreCompact stdin payload + snapshot artifact contents
      (original_task from in_message.txt, pipeline_stage from
      progress.json, last 5 lines of hook_events.jsonl, ISO timestamp)
    * Documents PostCompact JSONL confirmation record format
    * Registration in /workspace/.claude/settings.json with matcher ""
    * Exit-0 discipline emphasized (non-zero from PreCompact would block
      the compaction the operator opted into)
    * Cross-refs to compaction-api-opt-in, hook-settings-location,
      hook-event-logging, multi-agent-hook-observability,
      subagent-lifecycle-hooks
- CLAUDE/skills/compaction-api-opt-in.md
    * Added precompact-context-guard.md to the Related list with a
      one-line description of the pairing rationale

Idea 3: MessageDisplay Hook Skill + disallowed-tools Disambiguation
----------------------------------------------------------------

Why: Claude Code v2.1.152 introduced two related changes -- a new
`MessageDisplay` hook event that fires before an assistant message reaches
the user (first hook on the outbound path; complements
post-tool-output-sanitize which is inbound) and a CLI-native
`disallowed-tools:` (hyphenated) frontmatter key for skill/command files
that runs independently of KlodTalk's camelCase `disallowedTools:`
forwarder in run_agent.py. Without disambiguation, operators will mix the
two forms and get silent enforcement gaps.

Changes:
- CLAUDE/skills/message-display-hook.md (NEW)
    * Documents the MessageDisplay event (v2.1.152+) and its stdin payload
    * Three concrete KlodTalk use cases: ANSI strip, [STAGE: <role>]
      prefix injection, truncate-and-spill to
      /workspace/.klodTalk/team/current/message_overflow_<ts>.txt
    * Registration in /workspace/.claude/settings.json under
      hooks.MessageDisplay with matcher ""
    * Exit-0 discipline (non-zero blocks the response stream)
    * CLI version requirement section warning that older CLIs silently
      ignore the hook
    * Verify recipe with an ANSI-coloured example input
- CLAUDE/skills/disallowed-tools-frontmatter.md
    * Added "camelCase vs Hyphenated: Two Different Enforcement Paths"
      section with a comparison table:
        - `disallowedTools:` (camelCase) -- role files, KlodTalk-forwarded
          by run_agent.py
        - `disallowed-tools:` (hyphenated) -- skill/command files,
          CLI-native (v2.1.152+)
    * Rule of thumb + warning that wrong key is silently ignored
    * Note that both can be declared on a file that needs both paths
