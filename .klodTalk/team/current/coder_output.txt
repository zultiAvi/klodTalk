## Idea 2: `canary-phrase-guard` skill + hook script

What and why:
- Added a PostToolUse Write/Edit hook with `continueOnBlock: true` that detects
  placeholder/stub code in tool input (raise NotImplementedError, # TODO:, pass  #
  placeholder, FIXME:, XXX:, etc.) and exits non-zero with a stderr reason so Claude
  receives the rejection and retries.
- Capped at 3 consecutive blocks per file (counter file under /tmp/) to stay well
  below the v2.1.143 Stop-hook 8-block termination limit. After the cap is reached
  the hook logs a `canary_cap_reached` event to hook_events.jsonl and exits 0
  (pass-through).
- Follows the pre_tool_use_guard.sh style: jq with raw-fallback parsing, narrow regex
  deny-list, exit 2 with a stderr reason on match.

Files created:
- CLAUDE/skills/canary-phrase-guard.md  (new skill, three-tier format, summary
  double-quoted because it contains colons inside backticked phrases)
- server/utils/hooks/canary_phrase_guard.sh  (new, executable, ~140 lines, bash -n
  syntax-checked clean)
